🔀 Conditionals

Try if-else statements interactively:

// English - Conditional Logic

if (score >= 90) {
    score;
} else {
    if (score >= 80) {
        score;

🔁 Loops

Test while and for loops:

// English - Loops
// Loop examples with native keywords

// Simple loop - sum from 1 to 5
let sum = 0;
let counter = 1;

while (counter <= 5) {
    sum = sum + counter;
    counter = counter + 1;
}

sum;

⚡ Control Flow Examples

Advanced control flow patterns:

// English - Control Flow
let counter = 0;
let max = 5;

// Loop
while (counter < max) {
    counter = counter + 1;
}

let score = 85;

if (score >= 90) {
